# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾拒绝。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

## 红字票据（追溯减保退费）

退费以逐笔冲减明细为唯一依据：按原缴费记录的缴费比例分解退费（最大余额法到分），每笔明细引用原缴费记录ID、来源行号与原开票月份。开票月份取可选列`paid_month`（YYYY-MM，非法值按DATE隔离，哨兵值视为缺省），缺省取缴费记录effective所在月。同一保单同一开票月份的明细合并为一张红字票据；原缴费跨月时必须按原开票月份分别出票，不得并入当前月一票——冲减期间与税额各归原缴费月份。税额=金额×rate/(1+rate)，rate默认0.06，可由参数`tax_rate`覆盖；逐笔HALF_UP到分，票据税额为明细税额之和。红字金额记负，全部红字票据合计须等于退费合计（reconcile.invoices.balanced），否则不得结案。结案下载与逐笔票据结果同出一份票据台账，不另行重算。票据与明细ID由业务键（保单、原缴费记录、开票月份）哈希确定；同一退费重跑内容相同则不新增版本与票据。台账只追加新版本、当前版本指针原子拨动；生成中断时指针仍指上一完整版本，旧版本永不覆盖，原票关联与税务核对链不断。补缴（SUPPLEMENT）不属于红字票据范围。
